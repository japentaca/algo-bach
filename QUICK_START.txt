THREE WAYS TO RUN:

1. SIMPLEST - See Examples
   ─────────────────────────────────────────────────────────────────
   > node example.js
   
   Shows 5 working examples of different compositions

2. PROGRAMMATIC - Use in Node.js
   ─────────────────────────────────────────────────────────────────
   import { generatePiece } from './src/main.js';   // ES modules
   const piece = generatePiece({
     form: 'Chorale',
     mode: 'major', 
     key: 'C',
     duration: 4
   });

3. WEB PAGE - Static site (Vite), no server needed
   ─────────────────────────────────────────────────────────────────
   > npm install
   > npm run samples     (once: copies the samples from carrilion)
   > npm run dev         (http://localhost:41324)
   > npm run build       (static site in dist/; npm run preview serves it)

PARAMETERS:

  form:     Chorale, Prelude, Gigue, Allemande, Courante, Sarabande,
            Minuet, Fugue, Passacaglia
  mode:     major or minor
  key:      C, D, E, F, G, A, B (+ accidentals: C#, Db, etc.)
  duration: 1-150 bars

EXAMPLES:

  C Major Chorale, 4 bars:
  > generatePiece({form: 'Chorale', mode: 'major', key: 'C', duration: 4})
  
  D Minor Prelude, 3 bars:
  > generatePiece({form: 'Prelude', mode: 'minor', key: 'D', duration: 3})
  
  G Major Gigue, 2 bars:
  > generatePiece({form: 'Gigue', mode: 'major', key: 'G', duration: 2})
